\# Robot Arm Sim Lab



A hands-on robotics simulation and control project built with Python and MuJoCo.



\## Goals



\- Model robot joint states and coordinate data with NumPy.

\- Build and run a robot-arm simulation in MuJoCo.

\- Implement trajectory and safety control.

\- Record simulation data and evaluate task success.

\- Train a simple imitation-learning policy.

\- Prepare the project for ROS2 and Docker deployment.



\## Project Structure



\- `src/`: Python source code

\- `docs/`: technical notes and documentation

\- `assets/`: images and demo materials

\- `data/`: local simulation datasets

\- `tests/`: automated tests
